NSFW IMAGE CLASSIFIER — MODEL NOTICE AND ATTRIBUTION
=====================================================

The file `nsfw_model.tflite` bundled with Azm is the MobileNetV2
(224x224) NSFW detection model from the nsfw_model project by
Gant Laborde and contributors:

  Source:  https://github.com/GantMan/nsfw_model
  Release: v1.2.0 (`mobilenet_v2_140_224`, file `saved_model.tflite`)
  Classes: drawings, hentai, neutral, porn, sexy (in this order)

The model runs fully on-device inside Azm's accessibility service.
No image, screenshot, or classification result ever leaves the device.
